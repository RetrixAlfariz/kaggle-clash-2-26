# bitrase-1.algo-7 — protocol

This is a single bounded experiment. It loads the selected epoch from the completed bitrase-1.algo-6 checkpoint and freezes all neural emissions. Only a 15x15 linear-chain BIO transition matrix is fitted, using CRF negative log likelihood on a deterministic 4,000-document subset of v1 train. The initial state disallows I tags and illegal BIO transitions are masked, matching the existing exactly-K decoder semantics. No pretrained artifact, external data, dev labels, holdout, test data, or count-conditioned training is used.

The dev path always decodes with `decode_k` using the learned transitions; the neural raw shortcut is intentionally not used. Primary metric is known-K exact-slot accuracy, with entity F1 and boundary diagnostics. The experiment is exploratory and must be rejected unless it beats the frozen parent under the same dev protocol.

Pre-run root review corrections: verify parent checkpoint/vocabulary/source hashes; GPU emission inference in length-sorted batches32; transition fitting on CPU with one thread, Adam lr0.03, batch32,3epochs, gradient clip5, one optimizer update per batch. Training subset is sorted by SHA1 document ID, first4000. Token-unaligned train entities follow parent gold_tags behavior and are counted, not used as a reason to discard documents. All dev gold remains in metrics. Training uses ordinary CRF partition, no learned start/end scores, matching the decoder. The dev report is keyed by known_k for independent saved-prediction validation. Exhaustive three-token partition, padded batch equivalence, and finite gradients are checked before fit.
