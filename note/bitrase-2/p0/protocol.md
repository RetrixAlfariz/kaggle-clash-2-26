# bitrase-2 / P0 — Frozen direct-span probe

Status: implementation protocol, experimental candidate, not a promoted baseline. Target92% exact-slot;88% milestone. No pretrained, external corpus, reserved holdout, or automated Kaggle submission.

Use frozen epoch4 Byte-CNN/BiLSTM encoder from bitrase-1.algo-6, unchanged baseline sources. Capture256-dimensional input to its BIO linear layer with an external forward hook, eval mode and no gradients. Cache native hidden dtype losslessly; replay BIO logits/decisions and all6,943 known-K dev predictions before training. Prepared train/dev/vocabulary/checkpoint/cache sources and data are hash verified. Memory-mapped cache is indexed by document ID, not evaluation order.

Span universe: every aligned token interval of width1..16. Internal intervals are HALF-OPEN [a,b); endpoint states are h[a],h[b-1], character offsets bounds[a].start/bounds[b-1].end. Representation [left;right;product;mean;32dim width] has1056dimensions. FP32 per-document prefix sums supply means. Head: LayerNorm1056,Linear1056->256,GELU,Dropout.2,Linear256->8. Class order NONE,NAME,DATE,EMAIL,PHONE,ADDRESS,USERNAME,JOB_TITLE. No added loss or head feature ablation.

Train uses all55,582 documents. Positives are all representable gold; candidates overlapping unrepresentable gold are excluded from negative training only. Forced negatives: valid start-only/end-only offsets{-2,-1,+1,+2}, union epoch4 exact-K train false-positive spans. Exact gold label always overrides a nominated negative. Dedupe span boundaries; retain source tags. Random256 negatives sampled without replacement from the remaining eligible pool, refreshed each epoch using NumPy SeedSequence[seed,epoch,original_document_index]. Sorted universe/forced sets avoid unordered hash iteration.

Inclusion probability is1 for forced/positive and min(256,R)/R for random remainder R. Cross-entropy numerator is sum(CE/q), denominator is known eligible universe size summed over batch documents. In this fixed-size disjoint design, sum(1/q) equals that denominator; assert equality. No class weights or weight clipping. This targets full eligible-candidate CE in expectation; forcing hard negatives improves observation frequency, not their expected objective weight. Log weighted loss, positive loss/recall, and negative-stratum losses plus q/weight distribution.

Optimization: AdamW lr.001,wd.01,clip1,CUDA AMP,head only. One optimizer update per32 documents; head-scoring chunks capped32768 candidates, gradients accumulate with the SAME full-batch denominator until all chunks finish. Deterministically shuffle documents with Random(seed+epoch). Three discovery epochs, seed2026; evaluate full dev after each, select best exact-slot. No tuning sweep. All candidate labels are evaluated at inference, no pruning/thresholds/fallback.

Pre-fit runtime correction: initial float16 loss scale65536 overflowed on the first batch before any optimizer update. Preserve failed artifacts separately. Count retries separately, never drop positives or include failed attempts in logs. All hyperparameters/objectives above remain fixed; this is a numerical execution repair, not dev-based tuning.
